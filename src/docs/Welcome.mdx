## Install

```sh
npm install @mozilla/lit-web-components
```

```js
import '@mozilla/lit-web-components/foundation.css';
import '@mozilla/lit-web-components/components/moz-button';
```

These are standard custom elements, so they work in plain HTML and in any
framework. Typed React wrappers ship alongside them — see{' '}
<a target="_top" href="./?path=/docs/docs-getting-started--docs">Getting Started</a>{' '}
for the full setup.
